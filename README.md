# AI 对话记录

2026 创新基地班软件考核（第一题）—— STM32F407ZGT6 GPIO 输入输出与 EXTI。

本仓库是完成该题过程中与 AI 的对话记录，按主题分成六节。**代码全部由本人手写录入工程**，AI 只负责讲解原理、指出问题、给单个函数的写法。

## 工程环境

| 项目 | 内容 |
|---|---|
| 芯片 | STM32F407ZGT6（LQFP144） |
| 工具链 | STM32CubeMX + HAL 库，Keil MDK AC5 V5.06 |
| 系统时钟 | 16 MHz（HSI，未开 PLL） |
| 外设 | GPIO 输出（LED0=PF3、LED1=PF5、蜂鸣器=PF1）、GPIO 外部中断（KEY0=PC0、KEY1=PC2、KEY2=PF7、KEY3=PF8、WK_UP=PF9） |
| 电平 | LED 与蜂鸣器低电平有效；按键上升沿触发 + 内部下拉 |
